# Axler Visualizations

Interactive, bilingual visualizations for Sheldon Axler's *Linear Algebra Done Right*.

**Live site:** https://sellerbto.github.io/axler-visualizations/

The project is a small collection of explorable mathematical notes: each page isolates one idea and lets you manipulate the relevant matrices, vectors, or coordinate descriptions directly.

## Visualizations

- **3.51 — Matrix multiplication as linear combinations** — read a matrix product by columns or rows and see where the coefficients come from.
- **3.81 — Matrix of a product of linear maps** — follow a basis vector through two maps and see why composition becomes matrix multiplication.
- **3.82 — Identity operator between two bases** — keep a vector fixed while its coordinate description changes, revealing inverse change-of-coordinate matrices.
- **3.84 — Change-of-basis formula** — compare two coordinate routes for the same operator and see why `A = C⁻¹BC`.

## Languages

Every public page supports English and Russian from the same HTML file:

- `?lang=en`
- `?lang=ru`

## Stack

Plain HTML, CSS, and JavaScript. No build step is required; the site is published with GitHub Pages.
